# Rock Paper Scissors Game

A Python-based interactive Rock Paper Scissors game where the player competes against the computer.

## Description

The player selects Rock, Paper, or Scissors, while the computer generates a random choice. The program compares both choices, determines the winner, updates the score, and allows the user to play multiple rounds.

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a Draw

## Features

- Player vs Computer gameplay
- Random computer choice
- Winner determination
- Score tracking
- Multiple rounds
- Input validation
- Game rules
- Game history
- Save game results
- Reset score
- Simple and user-friendly console interface

## Technologies Used

- Python 3
- Random module
- DateTime module
- Functions
- Loops and conditional statements
- File handling
- Object-Oriented Programming
